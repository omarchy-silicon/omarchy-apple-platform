# Omarchy Apple Platform

This repository is the release authority and coordination plane for bringing Omarchy to every Apple Silicon Mac through a safe native installer, a version-locked platform stack, and board-level physical qualification.

The canonical program plan, acceptance contract, slice ledger, decision log, and append-only progress record live in [PROGRAM.md](PROGRAM.md).

Nothing in this repository should imply that an Apple device is supported merely because its SoC can be identified or its architecture is `aarch64`. A board is supported only when a signed platform release names it and links to complete physical qualification evidence.
