# F-05 candidate assembly

Candidate assembly accepts only the closed candidate-assembly input schema and emits a canonical structural manifest after every injected authority and content-addressed-store check succeeds. The command is read-only and structural verification remains `STRUCTURAL_ONLY`; promotion and release authorization remain outside this slice.

The candidate package artifact projection is an object keyed by artifact ID, so JSON object-key uniqueness closes the artifact identity set at the schema boundary; the embedded F-04 package index remains its owned array form. The JSON Schema also closes bounded identifiers and strings, exact source commit shape, nonempty unique collections, and the nine required gate positions. Lexicographic ordering of list identifiers and digest collections is a semantic constraint that Draft 2020-12 cannot express portably here; the generated consumer model enforces those lists as sorted and unique before any authority or CAS call. Object member order is not semantic and is normalized by canonical JSON.
